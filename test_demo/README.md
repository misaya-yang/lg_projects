# AI助手工具

一个简单的命令行AI助手工具，支持多种模型选择。

## 功能特点

- 🚀 支持多种AI模型选择
- 💬 简单的命令行交互
- 🛠️ 内置工具支持（如获取当前时间）
- 📝 清晰的输出格式

## 支持的模型

| 选择 | 模型 | 描述 |
|------|------|------|
| 1 | deepseek-v3:671b | 本地部署的DeepSeek模型（无工具） |
| 2 | gpt-4o | OpenAI GPT-4o模型（无工具） |
| 3 | deepseek-v3:671b | 本地部署的DeepSeek模型（带工具） |
| 4 | gpt-4o | OpenAI GPT-4o模型（带工具） |

## 安装依赖

```bash
pip install langchain langchain-openai langgraph pydantic
```

## 使用方法

### 基本语法

```bash
python apitest.py "你的问题" 模型选择
```

### 使用示例

```bash
# 使用模型1写诗
python apitest.py "写一首春天的诗" 1

# 使用模型2解释概念
python apitest.py "解释什么是机器学习" 2

# 使用模型3获取时间（带工具）
python apitest.py "现在几点了" 3

# 使用模型4进行创意写作（带工具）
python apitest.py "写一个科幻短故事" 4
```

### 参数说明

- `prompt`: 要发送给AI的提示内容（用引号包围）
- `model`: 模型选择（1、2、3 或 4）

## 输出示例

```
🚀 正在初始化模型 1...
🤖 正在创建AI助手...
📤 正在发送请求: 写一首春天的诗

📤 AI回复：
==================================================
春风拂面花满枝，
绿草如茵鸟语时。
万物复苏生机现，
春天美景入诗来。
==================================================
```

## 错误处理

工具包含完善的错误处理机制：

- 模型选择错误会提示有效选项
- 网络连接问题会显示具体错误信息
- API调用失败会给出详细错误描述

## 注意事项

1. 确保网络连接正常
2. 模型1和3需要本地服务器运行
3. 模型2和4需要有效的OpenAI API密钥
4. 提示内容建议用引号包围，特别是包含空格的内容
5. 模型3和4支持工具调用（如获取当前时间）
